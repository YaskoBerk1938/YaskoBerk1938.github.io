Privacy Policy

Last updated: November 14, 2026

Yasko is a personal content tool operated by Yasin Berk Karci. It is used only by its operator to prepare short videos and publish them to the operator's own YouTube channel. It is not offered to the public and no other user accounts exist.

YouTube API Services

Yasko uses the YouTube API Services. By using Yasko you agree to be bound by the YouTube Terms of Service. Information accessed through the YouTube API Services is also handled according to the Google Privacy Policy.

Information we access

When the channel owner signs in with Google (OAuth 2.0), Yasko requests access to:

  • upload videos, captions and playlists to the signed-in YouTube channel and edit their titles, descriptions, tags and scheduled publish time;
  • read the channel's own videos, playlists, comments and statistics (views, likes, subscribers);
  • read YouTube Analytics reports for the same channel (views, watch time, audience retention).

Yasko does not access any other user's account or private data.

How the information is used

The information is used only to publish the operator's own videos, show the operator a statistics page for the channel, and learn which of the channel's videos perform best so future videos can be improved. Yasko does not sell, rent or share this information with any third party and does not use it for advertising.

Storage and deletion

  • The OAuth token is stored only on the operator's own computer.
  • Channel statistics and comment snapshots are stored locally and refreshed or deleted within 30 days.
  • No data is stored on any server operated by Yasko.
  • You can revoke Yasko's access at any time from the Google security settings page. After access is revoked, the stored token stops working and all locally stored API data is deleted within 7 days.
  • To request deletion of any stored data, contact the operator at the address below.

Cookies

Yasko's local web interface stores a single session cookie in the operator's own browser to keep the operator signed in. It does not use tracking or advertising cookies.

Contact

Yasin Berk Karci, Riga, Latvia. Use the support email shown on the Google sign-in consent screen.
